AB Photography Photobooth V2

PRUEBA RÁPIDA
1. index.html incluye un MODO DEMO que permite revisar todo el flujo sin cámara.
2. Para usar la cámara real en iPhone/iPad, la página debe estar publicada por HTTPS.
3. Sube index.html, manifest.webmanifest y sw.js a GitHub Pages, Netlify o tu hosting.
4. En Safari acepta el permiso de cámara.
5. Puedes usar Compartir > Agregar a pantalla de inicio.

INCLUYE
- Diseño responsive iPhone/iPad
- Cámara frontal y trasera
- Modo demo
- Cuenta regresiva 3/5 segundos
- 1–4 fotos
- Tira 2x6 y formato 4x6
- Branding AB configurable
- Vista previa
- Guardar/compartir
- PWA básica/offline después de primera carga

PRÓXIMO
- PIN admin
- Diseños personalizados por evento
- Galería
- Guardado de originales
- Impresión/AirPrint
